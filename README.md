Token launch radar for Solana. It scores new token launches with the radar-2 model (implied value = TVL x peer multiple x growth x maturity x reach) and ranks them on a live dashboard with a 198-row board and a research dossier.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input /path/to/snapshot.json
```
